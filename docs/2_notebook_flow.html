How the notebooks share their results

The notebooks never call each other and never pass Python variables between them. Each one is a separate program. They “talk” only through folders on disk: one notebook or script saves files into a folder with an agreed name, and a later notebook opens that same folder and reads them.

Top band: the image folder. Middle row: notebooks and scripts, run left to right. Bottom band: the results folder. Solid arrows save files, dashed arrows only read them.

2. How does each notebook know where to look?

Every notebook and script follows the same three rules, so they always agree on the place and the file names:

  1. Same starting point. Each notebook first finds the project folder (the one containing src/deepfake_kyc). On Colab it clones the project from GitHub first. All other paths start from there.
  2. Same settings file. configs/base.yaml says where the images live (data.root: data/raw/real_vs_fake/real-vs-fake) and where results go (output_dir: outputs). Each experiment file in configs/experiments/ adds an experiment_name, which becomes the sub-folder name, e.g. outputs/02_effnet_frozen/.
  3. Same file names. Training always saves best.pt, config.yaml, history.csv and summary.json. Evaluation always saves eval_<name>.csv next to best.pt. Notebook 03 searches outputs/*/eval_*.csv, notebook 04 searches outputs/*/best.pt.

Bonus: best.pt also stores the settings it was trained with, so notebook 04 can rebuild exactly the same model and image size without guessing.

5. Watch out on Google Colab

Each Colab session starts empty. When the session ends, everything under /content (the cloned project, the images, and outputs/) is deleted. Each notebook re-clones the project, but the images and trained models are gone. Keep archive.zip and your results in Google Drive.
Notebook 05 saves to Drive, notebooks 03 and 04 look in the project. With SAVE_OUTPUTS_TO_DRIVE = True, notebook 05 saves into /content/drive/MyDrive/deepfake_kyc_outputs/<experiment>/. Notebooks 03 and 04 search <project>/outputs/, so they will say “nothing found”. Before running 03 or 04 in Colab, copy that Drive folder into the project’s outputs/ folder, or change their OUTPUTS_DIR to the Drive path.
Different notebooks can run in different Colab sessions. They do not share memory, only files. A result is visible to the next notebook only if it is in a folder that notebook can see, which in practice means Google Drive.
